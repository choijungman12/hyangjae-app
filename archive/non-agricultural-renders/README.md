# 격리된 이미지 — 사이트에서 사용하지 않음

이 폴더의 이미지는 **글램핑 텐트 내부(침구·소파), 화로대, 수영장, 식탁 세팅** 등
야영·숙박·취식을 연상시키는 장면을 담고 있어 `public/` 밖으로 옮겼습니다.

향재원은 **농산물 생산 시설**이며, 공간대여·야영·숙박·취식을 운영하지 않습니다.
이런 이미지가 사이트에 노출되면 실제 운영 내용과 다르게 읽힐 수 있어 배포 대상에서 제외했습니다.

## 남은 작업

`public/facility-images/` 의 나머지 이미지는 아직 전수 검수되지 않았습니다.
배포 전에 아래 기준으로 한 번 훑어 주세요.

**제외 대상** — 텐트 내부 침구/소파, 화로대·모닥불, 수영장, 차려진 식탁, 캠핑 의자
**사용 대상** — 재배 베드, 작물, 온실 설비, 센서·제어반, 노지 조경수·화훼, 판매장

## 현재 앱이 참조하는 시설 사진: 없음

앱 코드는 `public/facility-images/` 의 **어떤 파일도 직접 참조하지 않습니다.**
검수되지 않은 렌더링이 섞여 있어, 평소에는 설비 구조를 그린 벡터 도해를 씁니다.

| 그리는 것 | 컴포넌트 |
|---|---|
| 3단 다단 수경 베드 단면도 | `src/components/HydroponicBedArt.tsx` |
| 온실 평면도 · 투시도 | `src/components/GreenhousePlanArt.tsx` |
| 치유농업 프로그램 장면 | `src/components/CareProgramArt.tsx` |
| 브랜드 마크 | `src/components/WasabiMark.tsx` |

이 폴더와 `public/facility-images/` 의 이미지는 `/admin/content` 에서 업로드로 교체할 때의
**원본 후보**로만 보관합니다. 올리기 전에 위 기준으로 한 장씩 검수해 주세요.
